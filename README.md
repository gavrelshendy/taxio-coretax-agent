# Coretax Agent

Standalone desktop app for Coretax DJP automation used by [Taxio](https://github.com/gavrelshendy/Taxio). This repo hosts release builds only - source code lives in the main Taxio monorepo.

Download the latest release from the [Releases](https://github.com/gavrelshendy/taxio-coretax-agent/releases/latest) page, or use the direct link:

https://github.com/gavrelshendy/taxio-coretax-agent/releases/latest/download/coretax-agent.exe

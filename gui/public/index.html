Pilih entitas di sebelah kiri terlebih dahulu.

Impor massal e-Reporting Realisasi Investasi (Dividen) ke draft Coretax langsung dari Excel — form ini tidak punya impor bawaan.

  1. Login manual (tombol "Login Coretax" di atas), lalu klik "Buat Kasus Baru" di bawah — otomatis membuka kasus AS.39-01 sampai halaman Alur Kasus (~1 menit).
  2. Isi file template (sheet Info Umum, Dividen, Investasi), lalu pilih di bawah.
  3. Klik Impor. Data masuk otomatis ke tabel dan langsung disimpan — Anda tinggal periksa, lalu Create PDF → Sign → Kirim sendiri.
  4. File pembanding (crosscheck) dibuat otomatis setiap Impor — atau klik "Cek Hasil" kapan saja untuk membuatnya ulang dari tabel yang sedang tampil.

Data hanya masuk ke draft — tidak ada yang terkirim ke DJP sampai Anda menandatangani & klik Kirim sendiri.

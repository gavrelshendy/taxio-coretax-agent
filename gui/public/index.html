Impor Massal Dividen (AS.39-01) Impor e-Reporting Realisasi Investasi langsung dari template Excel ke draft Coretax.
  1. Klik tombol Login Coretax di atas, lalu tekan Buat Kasus Baru.
  2. Unggah file template .xlsx yang sudah terisi di bawah ini.
  3. Klik Impor ke Coretax untuk memasukkan data otomatis ke draft.

Data masuk ke draft — tidak dikirim ke DJP sampai Anda menandatangani sendiri.

Pengkreditan Pajak Masukan (per baris Excel) Tiap baris dicari lewat No Faktur, dicocokkan dengan data Coretax, lalu dikreditkan ke masa sesuai kolom MASA PENGKREDITAN.
  1. Pilih entitas di atas (harus PIC Coretax bertaut, bukan sesi manual).
  2. Unduh template bila belum punya, isi kolom A–J, lalu unggah di bawah ini.
  3. Klik Impor ke Coretax. Hasil per baris (SUKSES/GAGAL/DILEWATI + alasan) ditulis balik ke file dan disimpan di folder Downloads.
